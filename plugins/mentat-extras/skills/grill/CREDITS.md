# Credits

The interview in `grill` comes from the `grilling` skill by Matt Pocock in [mattpocock/skills](https://github.com/mattpocock/skills) (`skills/productivity/grilling/SKILL.md`): questioning the maintainer about a plan as a tree of decisions that depend on each other, looking facts up instead of asking for them, asking nothing whose answer hangs on a decision still open, and acting on nothing until the maintainer confirms. Asking one question at a time comes from that skill's earlier version (commit 170ad48); it later moved to asking every question it can in one numbered round.

Changes for Mentat: each question is one clickable `AskUserQuestion` prompt in the shape `rules.md` gives, with a "Stop here" option; it asks only the maintainer's decisions and decides implementation questions itself; stopping lists what was agreed and what is still open; the confirmed list feeds `mentat:propose` and is not agreement to build. Claude Code may offer a grill, and starts one only if the maintainer agrees. The skill is written anew; no text is copied.
