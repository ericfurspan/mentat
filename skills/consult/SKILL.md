---
name: consult
description: "Gets several AI agents' views on your question or idea. Arguments: the question or idea; add --web to ask without reading this repository."
argument-hint: "[--web] <question or idea>"
disable-model-invocation: true
---

The maintainer wants several points of view on one question or idea before trusting the answer. This runs once, then normal work resumes; it changes no record and no code, and starts no build session and no pull-request review; it still runs its own `mentat weigh` or `mentat consult`. Its weigh is not the weigh step of `mentat:propose` and does not replace it: do not call `mentat:backlog` for it, and do not post, keep or show its replies as "Replies in chat"; the short reply of step 5 replaces that. The text is what the maintainer typed after the command; if there is none, or only `--web`, ask for it and stop.

1. Choose the path, checking web-only first. Consult, with `mentat consult`, when the argument's first word is `--web`, the session is outside a git repository, the repository holds personal data, or `mentat:claude-review` has Codex off for the session. Otherwise weigh, with `mentat weigh`, when the text is a plan or idea for the git repository the session runs in, and consult for anything else. Once the path is chosen, a leading `--web` is dropped from the text. A repository holds personal data when its AGENTS.md says so or its tracked files plainly hold records about people; an AGENTS.md that says nothing about it counts as none.
2. Write the text to a file. The file holds only the maintainer's question or idea as given, with nothing pasted from the working tree (file contents, diffs) and nothing of Claude Code's own view; remove names, accounts, private project names, local paths and personal context, and if it cannot be asked without them, say so and stop. Put it in the repository's ignored working folder when the repository names one, otherwise in a temporary folder; never in an unignored path of a working tree. The text goes to each review tool that runs: OpenAI (Codex) and xAI (Grok, where installed), or those `~/.config/mentat/reviewers` lists, Anthropic (Claude) included; on the weigh path they also read the repository at HEAD, and on the consult path they get only the text, and may use it in web searches.
3. Write Claude Code's own one-line answer into a second file, on the weigh path as a verdict (do it, do it differently, or don't) with its main reason, using its own tools where they help, before the next step, so that the three views are independent.
4. Run `mentat weigh <file>` or `mentat consult <file>` in the background, with its output and errors saved beside the text: it takes minutes, can exceed a foreground command's limit, and runs the review tools in parallel. Wait until it exits before reading its output.
5. Read the finished output. A Grok sign-in refusal is not a stop: the Grok line carries it. Reply in six lines at most, the last one link, each of the others about 25 words or fewer, and nothing else; this skill sets the reply's shape while it runs:
   - `Consensus: <the answer to act on>`. When the views split, say so and name who disagrees on what. A claim none of them could verify is named here. On the weigh path, when the idea depends on uncommitted work or the output reports uncommitted changes, this line says the tools read HEAD only.
   - `Codex: <what Codex adds>` or `Codex: not weighed (<reason>)` or `Codex: not consulted (<reason>)`
   - `Grok: <what Grok adds>` or `Grok: not weighed (<reason>)` or `Grok: not consulted (<reason>)`
   - `Claude reviewer: <what the output's Claude section adds>` or `Claude reviewer: not weighed (<reason>)` or `Claude reviewer: not consulted (<reason>)`
   - `Claude: <what Claude Code's line from step 3 adds>`
   - Then one link to the saved output.
   On the weigh path every model line gives its verdict and main reason, even when they match the consensus. On the consult path a model line gives its CONSULT line with the main reason its reply gives, or where it differs, and does not repeat the consensus; when a model adds nothing beyond it, its line is `<Model>: agrees.` A line shows for each tool the output has a section for, and only those; when the command stops before any tool starts, each tool due carries the reason it gave. When no tool delivered, the Consensus line says the weighing or consultation did not happen, and how to proceed is asked after the reply, as `rules.md` "What goes to the maintainer" says.
