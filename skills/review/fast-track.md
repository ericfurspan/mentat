# Fast track

A fast track skips the Codex and Grok reviews for a change that cannot alter what code does or what an agent is told (typos, punctuation, broken links, formatting). Tests, CI and the final check still run. It is on only when the maintainer agreed to the proposal or asked for it; Claude Code never turns it on itself.

- The fast track and its reason are one line in the spec, written when it was agreed (`mentat:propose`): the backlog item's `## Spec` with an external backlog, else the issue's `## Spec`, else chat. After a compaction or a resumed session, read it back from there. A fast track agreed after the spec was written is a change of scope: update the spec.
- Before skipping review, check the complete final diff (`gh pr diff <N>`) against the rule above. On any doubt, and always for whitespace in source, configuration or lockfiles or for a URL a program fetches, run the normal review loop.
- Run no `mentat review` or `mentat review --grok`. Run `mentat ci <N>` after each push; it waits for CI on the head and reviews nothing. 0: go on. 3: the head moved; run it again. 4: failing checks: fix them, run the test command, push, and run it again; CI still running at the timeout, or 1: tell the maintainer.
- Then the final check, once the maintainer's comments are answered as Ready requires; Ready's review exit and the fingerprint's round do not apply. With no open hand check ("Final check"), rewrite the status line in full with the state `Not reviewed: fast track agreed by the maintainer`; the note's second sentence or a Verification line (`mentat:pr`) names every reviewer skipped, Codex and Grok (fast track agreed by the maintainer), and so does the one sentence after "You: merge #N." in chat.
- A later push, including after a hold, gets the diff check again. If it no longer qualifies, the normal loop runs from step 1 with all five rounds, and with Grok on that head if no Grok start comment exists; a hold reply then says all five rounds remain. If it does, the final check runs again, and a hold reply says the fast track continues, no round used.
