# Ready gate

A hand check is open when a requirement of the spec is one the maintainer checks by hand and the Verification does not say the maintainer checked it and what they saw. A builder's or Claude Code's own look does not close it. Then say no "Ready to merge: #N": the status line is `Blocked: <the hand check>`, the wait is written as `mentat:backlog` "Waits on the maintainer" says (with a backlog item, only on it plus one line atop the pull request; an external item is marked waiting, not as a merge wait), and the chat reply names the hand check in one plain sentence, plus any commands the wait sends to chat. Once the maintainer reports the check, record in the Verification that the maintainer checked it and what they saw, remove the wait and its line, and do the final check again. A step the spec or the description says is done after the merge stays in the item's wait block and does not hold back "Ready to merge: #N".

With no open hand check: mark a draft ready (`gh pr ready <N>`). If the repository owner is not the author, request their review (`gh pr edit <N> --add-reviewer <owner>`) unless their latest submitted review is `APPROVED` with a commit oid equal to `headRefOid` (`gh pr view <N> --json reviews,headRefOid`; not `reviewDecision`); if that read fails, request it. With an external backlog, start the item's merge wait (`mentat:backlog` "Marking a wait").
