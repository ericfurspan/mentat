# Credits

The reframing question in `zoom-out` ("Are we solving the right problem, and is there a better approach?") comes from the `step-back` skill by team-attention ([step-back-perspective-reset](https://mcpmarket.com/tools/skills/step-back-perspective-reset)). Saying plainly whether the goal or the plan itself should change, not only the next step, comes from course correction in the BMAD Method ([skills and agents](https://docs.bmad-method.org/reference/skills-and-agents/)).

Changes for Mentat: it runs once and then normal work resumes; it reads the pinned order issue, the other open issues and pull requests, and every maintainer message in the session for asks with no answer yet; it changes nothing while it runs.

Matt Pocock's `zoom-out` skill in [mattpocock/skills](https://github.com/mattpocock/skills) is a different thing (it maps code one abstraction level up) and is unrelated to this one.
