# Filing

Read this before filing an entry or item, and again after a compaction.

- An entry is filed only for a distinct outcome someone can act on (work to build, or a defect needing its own fix and check), after a search finds no open item tracking it; one review or audit is one entry listing its findings, and a remark or note is a comment on the item it concerns.
- Unasked work, an unasked proposal included, and an idea the maintainer raises mid-task go to the Inbox, settled in triage; a found defect and the maintainer's explicit request to file something go to Backlog. None of these goes through `mentat:propose`; the request in hand does.
- A hand step only the maintainer can run is written as `waits.md` says.
