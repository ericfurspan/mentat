# Pull requests open as normal pull requests, not drafts

Mentat opens a pull request as a normal one by default and keeps its state in a Status line at the top of the description, instead of GitHub's draft state. GitHub's free plan stopped offering draft pull requests in private repositories after 2026-10-18, so pull requests open the same way in private and public repositories (commit 61fcf78, pull request #206). Using drafts only where GitHub allows them was weighed again on 2026-11-18 and turned down.
