# The orchestrator agrees an item by default when nothing is open

The orchestrator in `mentat-lead:orchestrate` treats an item it plans as agreed with "Agree and build now", without asking the agreement question, when nothing is open for the maintainer: no decision of theirs was asked while planning, the plan check gave a verdict and no check said `DON'T`, and no hand check, standing assumption, fast track, bearing comment or advice against building is left for them to weigh. This reverses the rule, decided on 2026-11-18, that agreeing to build is always asked, because a question with only one sensible answer stopped planning without giving the maintainer a real decision; they still see each such item in one line and can say "later" while it is held. Typed planning sessions, chat requests and small requests still ask.
