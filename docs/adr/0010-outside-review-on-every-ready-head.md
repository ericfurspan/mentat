# Every Ready head gets its own outside review

Supersedes [0006](0006-one-outside-review-schedule-and-time-limit.md) in part, which ran the outside reviewers only on a head Claude's local review found clean, so a head whose local findings were all answered with nothing pushed reached Ready with no outside review at all. Now, where outside reviewers run, they run on a head once the sort of Claude's findings leaves nothing to push on it, whether that review found nothing or every finding was answered or left to be filed at the round limit, and a head whose outside run never started is not Ready; one adapter, one run per head and the one time limit stand. This keeps the promise that every Ready head had a second pair of eyes, at the cost of an outside run on heads that used to skip it.
