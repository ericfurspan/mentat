# Only the top orchestrator talks to the maintainer

Sessions the orchestrator in `mentat-lead:orchestrate` started could each ask the maintainer questions, and where the host could not start or message a session the orchestrator fell back to commands and lines the maintainer pasted between sessions. Now only the orchestrator talks to the maintainer: a session another session started asks them nothing and sends each question, wait, Ready and Hold line to the session that started it, which forwards their exact words back, and the orchestrator needs a host that can start and message sessions, so without one a session plans only and is not recorded as orchestrator. One place to answer keeps questions from scattering across sessions the maintainer does not watch, and dropping the paste fallbacks removes paths that were hard to keep right; the orchestrator's default agreement (0002) and its fresh session per batch (0003) stand.
