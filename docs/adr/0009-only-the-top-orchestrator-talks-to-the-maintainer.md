# Only the top orchestrator talks to the maintainer

Sessions the orchestrator in `mentat-lead:orchestrate` started already sent their questions to it, but where the host could not start or message a session the orchestrator gave the maintainer commands and lines to paste, and a session their command started asked them its own questions; the rules for forwarding also sat in core. Now only the top orchestrator talks to the maintainer: a session another session started, a planning session included, asks them nothing and sends each question, wait, Ready and Hold line to the session that started it, which forwards their exact words back; the orchestrator needs a host that can start and message sessions, and without one a session plans only and is not recorded as orchestrator. One place to answer keeps questions from scattering across sessions the maintainer does not watch, and dropping the paste fallbacks removes paths that were hard to keep right; the orchestrator's default agreement (0002) and its fresh session per batch (0003) stand.
